How these numbers are measured

  • Each question is asked on every engine several times, with paraphrases, so one lucky answer can't move the score.
  • Rates show a 95% range. “Up” or “down” is only used when the change passes a statistical test.
  • Failed or blocked captures count as missing data, never as “not mentioned”.
  • Sponsored placements are removed from organic numbers and reported separately.
